# Working in this repository

- Never add Claude as a co-author or co-committer. No `Co-Authored-By` trailer,
  no "Generated with" line, nothing of the kind in commit messages or pull
  request descriptions. Commits are the author's alone.
- Commit subjects are short changelog lines in the past tense: "Added bloom
  effect", "Removed header rule", "Fixed jagged card edges". Technical, under
  about 60 characters, no prose. A body only when something needs explaining,
  in short bullets.
