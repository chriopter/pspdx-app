# Working in this repository

- Never add Claude as a co-author or co-committer. No `Co-Authored-By` trailer,
  no "Generated with" line, nothing of the kind in commit messages or pull
  request descriptions. Commits are the author's alone.
- Never commit or push unless asked to in that moment. A request to change
  code is not a request to commit it, and a commit is never a push.
- Commit subjects are short changelog lines that say what is now true or
  what came in or went out: "Added bloom effect", "Removed header rule",
  "Fixed jagged card edges", "UMD sign now matches the real disc
  silhouette". Never a narration of the edit -- no "Changed X to Y",
  "Updated", "Modified", "Tweaked", "Stabilize". Technical, under about 60
  characters, no prose. A body only when something needs explaining, in
  short bullets.
