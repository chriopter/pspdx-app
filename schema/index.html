PSPDX standard

A small .pspdx file in your repository tells PSPDX where your PSP homebrew lives, so it can be listed, installed and updated.

Schemas

  • pspdx-v1.json — the .pspdx file
  • catalog-v1.json — a catalog of apps

Example

Every field of the demo app; only schema, source and name are required.

{
  "schema":      "https://chriopter.github.io/pspdx/schema/pspdx-v1.json",
  "source":      "https://github.com/chriopter/pspdx-demo",
  "name":        "PSPDX Demo",
  "type":        "homebrew",
  "tags":        ["demo"],
  "author":      "chriopter",
  "summary":     "Hello, PSP. A demo listing for PSPDX.",
  "description": "A hello world for the PSP, published the way a listed app is: a .pspdx in the repository, a release with the EBOOT.\nX says hello again, HOME leaves.",
  "license":     "MIT",
  "installdir":  "PSP/GAME/PSPDXDemo"
}

One more field, listed_by, is set only by a list that serves a .pspdx for a project without one.
