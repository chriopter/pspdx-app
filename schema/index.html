PSPDX standard

PSPDX (PSP Download Index) browses, installs and updates homebrew on a PlayStation Portable. It reads two kinds of file.

.pspdx — the file in your repository

A small file in the root of a homebrew's repository that says what the app is and where it lives; only schema, source and name are required.

Schema: pspdx-v1.json

{
  "schema":      "https://chriopter.github.io/pspdx/schema/pspdx-v1.json",
  "source":      "https://github.com/chriopter/pspdx-demo",
  "name":        "PSPDX Demo",
  "type":        "homebrew",
  "category":    "demo",
  "author":      "chriopter",
  "summary":     "Hello, PSP. A demo listing for PSPDX.",
  "description": "A hello world for the PSP, published the way a listed app is: a .pspdx in the repository, a release with the EBOOT.\nX says hello again, HOME leaves.",
  "license":     "MIT",
  "installdir":  "PSP/GAME/PSPDXDemo"
}

One more field, listed_by, is set by a catalog that lists an app whose repository has no .pspdx of its own.

catalog.json — the list of apps

Many .pspdx files gathered into one file with their releases and artwork, so the PSP gets every app in one request. Anyone can publish one; the .pspdx stays what counts.
