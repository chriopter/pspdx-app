PSPDX standard

A small JSON file that says where a PSP homebrew lives. Put a .pspdx in the root of your repository, publish a release with the EBOOT, and PSPDX can list, install and update it on the PSP.

Schemas

SchemaFor
pspdx-v1.jsonThe .pspdx file an author keeps in the repository, or a list serves for a project that has none
catalog-v1.jsonThe catalog.json a list publishes: every app with up to its 20 newest releases

Both are JSON Schema 2020-12. Any validator can check a file against them.

A .pspdx

Only schema, source and name are required:

{
  "schema": "https://chriopter.github.io/pspdx/schema/pspdx-v1.json",
  "source": "https://github.com/chriopter/pspdx-demo",
  "name":   "PSPDX Demo",
  "tags":   ["demo"]
}
FieldRule
schemaRequired; this schema's URL
sourceRequired; an https URL, on GitHub the repository
nameRequired; 1–40 characters
typehomebrew (default), plugin or iso
tagsUp to 8 words, each up to 24 characters; game, emulator, app and demo get a tab
installdirPSP/GAME/<folder>; defaults to the repository name
summary, author, licenseUp to 60 characters each
descriptionPlain text, up to 2500 characters, newlines allowed
listed_byThe home page of a list that serves this file for a project without one

The full rules, what comes from the release and what a catalog adds: the PSPDX standard.

Check it while you write

In VS Code, add this to your settings:

"files.associations": { "*.pspdx": "json" },
"json.schemas": [{ "fileMatch": ["*.pspdx"],
  "url": "https://chriopter.github.io/pspdx/schema/pspdx-v1.json" }]
